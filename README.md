# Retrieving_SrFeO_from_the_Materials_Project  

To retrieve crystal structures for SrFeO₃ (cubic perovskite), Sr₂Fe₂O₅ (brownmillerite), and intermediate phases programmatically, use the official Python client libraries for the Materials Project (mp-api)

* Retrieving from the Materials ProjectInstall the client via pip install mp-api. You will need a free API key from your Materials Project Dashboard.
